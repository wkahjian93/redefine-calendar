# REDEFINE Calendar

One team calendar for REDEFINE: everyone sees who is busy, private events show as "Busy", activities (A/O/P/F/C, ANP, MAE, ratios) are counted from confirmed events, comments + pop-ups (no chat), and AI import from calendar photos.

See HOW TO USE.md, GO LIVE.md, TEST RUN.md. Run tests: node test.js. Preview: node tools/serve.js (port 5200).
